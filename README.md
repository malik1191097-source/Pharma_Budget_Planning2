# 💊 Pharma Budget Planning Dashboard | Excel

## 📌 Project Overview

The **Pharma Budget Planning Dashboard** is an Excel-based data analytics project designed to analyze pharmaceutical sales performance, prescription quantities, profitability, and market segment trends. It transforms raw pharmaceutical data into meaningful insights using Excel dashboards, Pivot Tables, and data visualization.

This project helps users understand supplier performance, compare market segments, and evaluate business profitability to support data-driven decision-making.

## 🎯 Project Objectives

- Analyze prescription (Rx) quantities across different suppliers.
- Evaluate pharmaceutical profit and sales performance.
- Compare performance across Animal, Human-OTC, and Human-Rx market segments.
- Identify leading suppliers based on prescription quantity and profit.
- Present key business insights through an interactive Excel dashboard.

## 📊 Key Performance Indicators (KPIs)

- **Total Rx Quantity:** 214,808
- **Total Rx Profit:** 1,523,588.63
- **Suppliers Analyzed:** Competitor A, Competitor B, and Ortex
- **Market Segments:** Animal, Human - OTC, and Human - Rx

*These figures are based on the workbook's Pivot Table summaries.*

## 📈 Key Insights

- **Ortex** recorded the highest prescription quantity among the three suppliers.
- **Ortex** also generated the highest total Rx profit in the supplier comparison.
- The **Human - OTC** segment contributed the largest prescription quantity.
- The **Animal** segment generated the highest total Rx profit among the three market segments.
- The dashboard provides a consolidated view of supplier and market segment performance.
